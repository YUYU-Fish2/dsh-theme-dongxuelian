## 社区共存边界

只读核对用户已装包的元信息及公开源码，使用其现成文件在新 `.research/coexist-home` 与 `.research/coexist-workspace` 启动，没有修改或重新安装用户插件，也未带入模型凭据。

- `dsh-whale-widget@0.4.2`（MIT）：独立`/dsh-whale`资源/脚本与自己的挂件；实际可见，因隔离环境不带凭据而显示余额未配置，并有`NO_KEY`警告，未据此判主题失败。
- `dshmarket@1.66.42`（MIT）：主要使用settings和shell.overlay；实际“插件市场”设置入口可见，没有与本主题两处槽冲突。
- `dsh-better-sidebar@0.28.0`（MIT）：源码往同一header utilities列表注册独立id、order10/20，本主题id独立、order100；未发现品牌槽直接替换。但本轮隔离窗口没有确认其设置/工作台入口激活，**只能给出源码边界与启动尝试，不能宣称运行共存通过**。不修改第三方插件来掩盖该限制。
- 合成会话中本主题两处头像都存在，页面无`data-slot-error`。截图 [隔离共存窗口](screenshots/p5-community.png)。这不是用户现有desktop profile的共存结论。
