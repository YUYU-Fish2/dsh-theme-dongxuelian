## 发现与修正

实际检查发送按钮计算值时发现背景仍为 `rgb(65,118,230)`。沿按钮匹配样式定位到官方 `.RlGAzG_primary` 使用 `--dsw-alias-button-info-fill`，不是 P2 已覆盖的 primary pair。宿主 theme 源码确认 info-fill/hover 两项均存在。

在 `client.js` 将 info-fill 映射 `#96536A`、info-hover 映射 `#7E4257`；浅色 token 从24增至26。没有依赖该 hash 类名或写选择器，禁用 opacity=0.4 和宿主交互保留。该局部颜色映射按项目规则用实际预览和官方 token 存在性验证，不添加镜像数值测试。

刷新真实宿主后发送按钮计算背景为 `rgb(150,83,106)`，仍为 disabled、opacity=0.4。对照 [修正前焦点截图](screenshots/p4-keyboard-focus.png)与 [修正后玫瑰色/焦点截图](screenshots/p4-rose-focus.png)。截图使用本地合成会话，没有模型调用。
