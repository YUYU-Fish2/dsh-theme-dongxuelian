## 缺陷与修复证据

1. 其他监听在 `overrideTokens` 返回 disposer 前同步切深色，会留下浅色层并保存旧 disposer。回归复现深色和停用后均有残留，改为串行操作、读取最新 service 状态。
2. 同步事件中停用也遇到 disposer 尚未返回的窗口。回归复现后，每轮收敛将 `stopped` 纳入目标状态，返回 disposer 后仍能释放。
3. 真窗口复现：同步 release 嵌套发出新快照后，宿主 ThemePresenter 继续渲染外层旧快照，深色 DOM 仍残留奶油色。补呈现层回归，改用 `queueMicrotask` 合并处理，避免在宿主派发中嵌套发布；窗口往返切换已复验。

独立 reviewer 最终复查未发现新的必须修复问题，并独立重跑 7/7。范围为 P2，不代表 P3/P5 验收。
