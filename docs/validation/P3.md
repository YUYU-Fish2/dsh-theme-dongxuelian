## 路由与生命周期

- 唯一前缀 `/dongxuelian-theme/assets`，Map 只允许两张 WebP；原文路径去查询串后精查，不解码别名，不把用户输入拼为磁盘路径。
- GET/HEAD，正确 WebP MIME/长度、nosniff、no-cache；HEAD 只读 stat。已知文件其他方法 405，未知/穿越 404；文件故障 500，不泄漏磁盘位置。
- `ctx.inject(['webServer'])` + `scope.effect(register)` 绑定路由生命周期；客户端用宿主共享 React，无新增运行依赖。
- `sidebar.brand.mark` 的有限 `priority: -10` 在实测中覆盖官方默认项，深色/停用回退；header 为 `conversation.session.header.utilities` 列表项，独立 id，不替换 leading、整 header 或按钮。
- `slots.inject` 跟随声明，浅色一次事务拥有 theme 层和两个控制器；第二处失败逆序回滚；注册过程同步停用后返回的 disposer 仍释放。

### 隔离真实 Web 宿主

使用 `.research/test-home/profiles/theme-test`、官方插件管理开关与新生成的正常认证链接，没有关闭鉴权或操作用户 desktop profile。

- 初始浅色：头像自然尺寸192px、实际24×24、pointer-events none，背景 `#F7F4EF`。
- 深色：头像节点0，背景 `#151517`；回浅恢复。官方停用：头像0、背景 `#fff`，GET 图片返回404；重新启用恢复，捕获 warn/error 为空。
- 实际 Host：GET avatar 200、image/webp、26864字节；HEAD sidebar 200、长度23998、正文0；POST已知文件405；编码穿越404。
- 合成会话：通过官方 `sessionController.create` 与 `sessions` API 在隔离 home 写一条明确标注的本地合成 user/message（官方 `surfaceOp: 'append'`）。**没有调用模型**。DOM 两处头像均加载成功24×24，header 更多操作可展开，侧栏收起/展开可用；深色两处同时释放，回浅恢复，warn/error为空。
- 会话截图前读取 `innerWidth=1100, innerHeight=800, DPR=1`；新建浏览器标签会恢复默认尺寸，因此重新施加并读回 viewport 后才保存会话证据。
