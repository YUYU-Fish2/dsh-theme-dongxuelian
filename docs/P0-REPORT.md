## 官方接口与实现边界

- 本机 Theme 服务提供 `register()`、`overrideTokens()` 和 `theme/change`。覆盖层按来源管理并返回 disposer；令牌值要求 `{ light, dark }` 对。优先使用覆盖层，避免强制改写用户主题偏好。
- 已在安装包确认基础背景、面板、主次文字、边框、主按钮、输入框、侧栏和代码块所需令牌存在。最终使用量以 P2 实际组件效果为准，不把“名称存在”当成所有组件已验证。
- 侧栏候选为 `sidebar.brand.mark`，顶部候选为 `conversation.header.leading` 或合适的会话 header 子槽，空状态候选为 `conversation.hero.brand.mark`。这些是具体已有插槽，并非角色专用接口；占用、尺寸及替换行为需验证。
- 不替换整个 sidebar、header 或 conversation。若现有 single 槽被占用，应核对优先级与回退规则；小头像不应导致原有控制按钮丢失。可选空状态插画没有合适位置时延后，不强行重做布局。
- 本机 Desktop Host 明确使用 `ctx.webServer`，可研究官方路由注册方式。P3 资源文件采用唯一命名的白名单路径，生命周期内注册与释放，验证桌面实际页面请求；不内联成 data URI 或 JavaScript 图片 chunk，不开放任意文件读取。
- 首版重点为用户提出的浅色配色；深色处理须保留可读性与原有选择。P1 明确是否沿用官方深色值或在深色时释放覆盖，不自动扩展一套复杂深色设计。
- 首版不增加设置面板、复杂动画、全屏壁纸、字体依赖或冲突检测系统。使用 DSH 自带启停机制；多个主题同时覆盖相同令牌时存在顺序影响，应在安装说明与测试中明确。
