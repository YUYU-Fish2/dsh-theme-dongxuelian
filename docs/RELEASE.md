# 0.1.0-preview.2 发布说明

面向DSH `0.2.1-rc.2`的本地预览候选，采用用户选定的B彩铅抱书横幅。没有发布npm、GitHub Release或推送远端，没有安装到日常profile。安装与移除见[INSTALL](INSTALL.md)。

## 内容

- 26项浅色官方Theme token：纸白底、灰蓝侧栏、靛蓝强调，保留语义色、语法高亮和字体。次文字按最弱选中底色加深到#5C6578。
- 侧栏保留24px品牌头像，取消大头像水印。宽空态左侧标题/输入、右侧人物/蓝花/书；聊天以不透明纸白阅读面保护正文，右侧留观景带。窄列恢复宽输入，极窄聊天优先正文。
- 图在官方会话content子容器的负层级伪元素中绘制，不拦截操作，不覆盖插件/设置等全局页；无动画、轮播或新增设置。
- 独立头像WebP 26864B，抱书WebP 222484B，共249348B。旧sidebar-character保留在源码历史中，撤出运行路由与包；母版PNG和三幅备选不打包。
- Host固定白名单仅avatar/reading，支持GET/HEAD；拒绝任意文件路径。深色、停用与卸载释放颜色、头像、场景与路由，不改用户主题偏好。
- 原生JS、共享宿主React、零第三方运行依赖，无编译或安装生命周期脚本。

## 验证与限制

P8通过18项回归、语法/包契约、真实官方ModuleLoader及26token检查；真实隔离Web完成空态和聊天各九组尺寸/CSS缩放、明暗/启停、菜单/工具卡/侧栏收放，真实Host停用后两项资源GET/HEAD均404。独立审核无需修复发现，明确本项目路径jscpd为0 clones。

800/1100/1440px为IAB viewport，100/125/150%为CSS zoom，深浅为系统媒体偏好模拟。真实聊天/read/附件历史在P5完成，本次读取该历史复核；一次多行输入自动化误触提交在模型请求前因隔离环境NO_ADAPTER失败，未新增成功模型请求或配置凭据。

未实测原生桌面、系统DPI/浏览器原生缩放、其他平台、长会话列表压力。better-sidebar实际激活与多主题覆盖顺序未确认。市场和挂件的历史共存观察不能替代新版本完整兼容保证，继续标为preview。

源码证据在`docs/validation/P8.md`；最终tgz的精确清单、校验与新隔离home安装/停用/卸载/重启结果另见`docs/validation/P6.md`。归档及SHA256清单位于本地`release/`，校验清单不放入tgz；不要使用旧preview.1包或其哈希。

## 素材与许可

场景由内置imagegen按用户选定的B彩铅参考另绘；头像来自此前原课表图标参考的另绘母版。已获授权的本地处理仅LANCZOS等比缩放和格式编码，没有裁切、修脸、合成、去背景或改角色身份。外部二创只参考配色构图，没有复制打包。

项目代码MIT许可；开发用loader检查脚本参考oil-oil公开MIT方案，归属见包内THIRD_PARTY_NOTICES。运行包没有打包参考主题代码或React副本。角色出处记录不等于官方授权或第三方图片转许可。见[场景说明](../assets/scenes/README.md)和[头像说明](../assets/characters/README.md)。
