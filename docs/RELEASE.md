# 0.1.0-preview.3 发布说明

面向DSH `0.2.1-rc.2`的本地预览版。按用户批准的宽屏示意重新生成抱书场景，收紧首页与聊天中间空白、统一暖纸白氛围并保留阅读实底。未发布npm或GitHub Release；日常安装按本机用户明确授权执行。安装与移除见[INSTALL](INSTALL.md)。

## 内容

- 26项浅色官方Theme token：纸白底、灰蓝侧栏、靛蓝强调，保留语义色、语法高亮和字体。次文字按最弱选中底色加深到#5C6578。
- 侧栏保留24px品牌头像。宽屏使用最多1920px共同构图区，首页输入从500px平滑增加到880px；聊天正文默认最多1040px、有限阅读区与输入对齐，人物不再贴窗口最右。窄列恢复原阅读优先布局。
- 图在官方会话content子容器的负层级伪元素中绘制，不拦截操作，不覆盖插件/设置等全局页；无动画、轮播或新增设置。
- 独立头像WebP 26864B，新抱书WebP为1536×1024、308130B，共334994B；场景保持3:2等比、局部四边渐隐。旧场景母版保留源码历史，PNG母版/用户截图/整页生成示意不打包。
- Host固定白名单仅avatar/reading，支持GET/HEAD；拒绝任意文件路径。深色、停用与卸载释放颜色、头像、场景与路由，不改用户主题偏好。
- 原生JS、共享宿主React、零第三方运行依赖，无编译或安装生命周期脚本。

## 验证与限制

P9使用既有18项回归、语法/包契约、真实官方ModuleLoader及26token检查。最终视觉只做正常使用必要验证：1265×817与2559×1395的首页/聊天、代码/工具卡/菜单、明暗及官方启停和资源恢复。独立审核检查CSS范围、比例、人物/正文关系和生命周期；查重使用本项目明确绝对路径。

当前窗口为隔离Chrome viewport，深浅为媒体偏好模拟；不是Windows系统DPI实测。聊天/read内容来自P5隔离历史，历史NO_ADAPTER失败记录保留，不把它当新请求或布局错误。本轮不发送模型请求、不配置凭据，也不再扩大压力或全平台矩阵。

用户截图已确认旧主题在原生桌面显示；新版视觉在隔离Web验证。系统DPI、其他平台和所有插件组合未逐项验证，继续标为preview。保留日常五项插件及配置的安装核对，不强制重启用户DSH。

源码证据在`docs/validation/P9.md`；旧P8/P6记录仅作历史。新包精确清单为`release/preview.3-manifest.json`，归档和SHA256清单位于本地`release/`，不放入tgz；preview.2旧归档和标签保留历史。

## 素材与许可

场景由内置imagegen根据用户批准的整页示意及原B彩铅参考重新生成；头像沿用原课表图标参考的另绘母版。新场景仅做原尺寸WebP编码，没有本地裁切、修脸、合成或去背景。外部二创只参考配色构图，没有复制打包。

项目代码MIT许可；开发用loader检查脚本参考oil-oil公开MIT方案，归属见包内THIRD_PARTY_NOTICES。运行包没有打包参考主题代码或React副本。角色出处记录不等于官方授权或第三方图片转许可。见[场景说明](../assets/scenes/README.md)和[头像说明](../assets/characters/README.md)。
