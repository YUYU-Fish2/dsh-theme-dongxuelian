# 0.1.0-preview.6 发布说明

修复窗口模式重新出现的竖直割裂：原先仅聊天列≥1100px才撤掉实色阅读板，现所有尺寸scroll透明、全列；列≥900px复用左阅读右人物构图，900–1099px人物按窗口高度等比缩放并自然柔边，向右偏移144px以避开正文。更窄窗口取消人物预留带、减弱插画墨迹，文字和输入不参与淡化。全屏既有几何保持。

没有重新生成素材、固定字号、新增依赖或修改生命周期/宿主核心。字体大小继续由DSH官方设置控制。窗口1310×790、全屏1625×968、窄1024×817和800×817已做隔离实窗验证；18项回归/check通过。已知首次宽度拖动空程、官方侧栏/代码卡差异仍保留。本轮部署与限制见源码docs/validation/P12.md，不把安装当日常窗口热加载。

运行包仍为15文件、三项WebP391512B，PNG母版、截图、用户参考、测试与缓存不打包；精确manifest及SHA见本地release。未自动推送GitHub、发Release或npm。素材来源与许可沿用下方历史说明。

## preview.5历史说明

面向DSH `0.2.1-rc.2`的预览版。按用户示例调整整页纸面：复用P9彩铅抱书场景，新增独立纸纹，让侧栏、标题和聊天背景连贯；撤掉宽列聊天中的实色阅读板和直线柔边，滚动条恢复到窗口右缘。用户已要求将此版安装到本机DSH并推送现有GitHub仓库。未发布npm或GitHub Release。

## 内容

- 26项浅色官方Theme token，主文字改为蓝墨色#2C4268，侧栏选中为浅蓝；保留语法高亮、字体和官方控件。文字和消息不参与插画的透明度或渐隐。
- 宽列聊天使用最多1920px共同构图区，正文最多960px，输入卡比正文宽160px；仅定位阅读和输入座，滚动区域保留整列宽度。小列保留阅读优先布局。
- 场景放在会话根的单一负层级伪元素，标题至底部连贯，pointer-events:none；人物右移24px，仅柔化插画层。插件/设置等全局页不铺聊天场景。
- 侧栏保留24px品牌头像。头像26864B、场景308130B、新纸纹56518B，三项WebP共391512B；PNG母版、用户参考、截图、测试与缓存不打包。
- Host固定白名单提供avatar/reading/paper，支持GET/HEAD；深色、停用与卸载释放主题覆盖和路由，不写用户主题偏好。
- 原生JavaScript、共享宿主React、零第三方运行依赖，无编译或安装生命周期脚本。

## 验证与限制

源码已完成18项主题/Slot/HTTP回归、语法/包契约检查、明确项目路径的本地查重及限定只读复核。真实隔离Chrome检查覆盖1625×968（示例同尺寸）、2331×1388和1265×817，以及菜单、输入后清空、滚动、侧栏收放、明暗和官方启停。聊天来自既有隔离历史，没有发送新的模型请求。

这是预览版，视觉仍有已知差异：宿主侧栏280px，示例约230px；字体、消息与代码卡沿用宿主；首次拖动正文宽度仍有空程。纸纹与场景柔化的视觉判断不能由测试通过代替。没有声称与示例完全一致。

新版窗口验证采用隔离Web viewport与媒体偏好模拟，系统DPI、其他平台及所有社区插件组合未逐项验证。日常安装使用官方CLI，不强制退出正在工作的DSH；安装成功不代表当前原生窗口已重载。

源码证据见`docs/validation/P11.md`，本次打包/安装/上传证据见`docs/validation/P11-DEPLOYMENT.md`。包清单为`release/preview.5-manifest.json`，SHA256见本地`release/SHA256SUMS.txt`。旧preview.4等归档保留，可通过官方CLI重装旧包回退。
