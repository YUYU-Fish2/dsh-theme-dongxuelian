# P1-A 角色与视觉规范（草案）

日期：2026-10-19。状态：DSH 起草、Codex 审核修订的 P1 规范；图片生成与验收进度见第 8 节，不宣称真实 DSH 界面效果已验证。
范围仅本文件：不涉及插件实现、资源路由、安装与权限。

## 1. 输入与三条路线

用户于 2026-10-19 回复“继续干”，并补充“图片你可以沿用风格继续生成，不一定要弄同一张图片”，即确认 P0 推荐路线、确认原图作为风格参考，并授权按该风格创作新素材。P0 已定位原图为 `launcher-icon-source.webp`（原课表项目 `DongXuelian-Custom-Timetable`，固定 HEAD `0e79863`）。

| 路线 | 做法 | 判断 |
| --- | --- | --- |
| A. 沿用同一张原图 | 直接裁切、缩放原图作头像/侧栏图 | 不采用。原图为整张课表，小尺寸信息过密，且用户已授权按同一风格另绘 |
| B. 参考原图新绘两项 | 按已观察特征重绘侧栏角色与头像，不复制像素 | **推荐**。与用户“沿用风格继续生成”的授权一致，可控制透明背景与小尺寸 |
| C. 完整新角色重设计 | 补全服装、全身、背面与新设定 | 不采用。原图大半身体被遮住，等于凭空发明；本轮也不需要全身素材 |

推荐 B 的理由：保留可核对的识别特征，不把“未看见的部分”写成设定，同时适配小尺寸。新绘不是角色权利或发布许可的证明；本轮授权覆盖当前项目的素材创作，公开发布范围在 P6 单独记录。

## 2. 已知特征与未知部分（严格区分）

以下为 **Codex 对原图的实际观察**，本稿据其整理；DSH 本轮未直接打开该图片，不声称亲自查看。

已知（可见）：
- 位置与姿态：角色在课表画面右下角，双手趴在边缘，身体与服饰大部分被遮挡。
- 头发：浅白偏淡紫，顶部有一缕明显翘起的发束。
- 面部：蓝色眼睛、半睁、平静偏困倦的表情；Q 版大头。
- 右侧配饰：白色五瓣花、绿色叶片、蓝色蝴蝶结、下垂的蓝色晶体状饰件。
- 线条与上色：深蓝轮廓，线条断续且有重复描边；蜡笔/水彩式填色，带留白与颗粒，形状简化。

未知（不得推断、不得补全）：
- 被遮住的完整服装、下装、鞋、完整发型与发长、背面设计。
- 角色的官方设定、身高、年龄、配饰的具体材质与结构。
- 原图以外的动作与表情不作为角色既定设定；用户允许新绘，可在保留识别特征的前提下小幅调整构图与姿态。

规则：新绘只允许在“已知”范围内发挥；需要新增的部分（如露出一点肩线）保持中性、低信息量，不引入新服装设定。

## 3. 两项素材与画风规格

本轮最多两项当前素材，均由 Codex 用 imagegen 生成并做视觉验收；DSH 不调用图片工具，也不代判定“已验收”。

1. 侧栏角色（文件 `assets/characters/sidebar-character.png`）：透明背景，头部加趴在边沿的双手；不画全身，不做底板、不做全屏背景。
2. 头像（文件 `assets/characters/avatar.png`）：同一角色的头像，构图更紧，保留发束、蓝眼与右侧花/结/坠饰组合。

画风约束：
- 手绘线条：深蓝、略带抖动、断续与重复描边；允许线头不完全闭合，不做均匀矢量描边。
- 头身比：Q 版大头；侧栏图以头与手为主，不引入比例争议。
- 填色：蜡笔/水彩质感，保留纸张颗粒与留白；不做高光塑料感、不做商业精细动漫插画、不做厚涂。
- 蓝色只作角色局部色（眼睛、蝴蝶结、坠饰、轮廓），**不得**外溢为界面主色或大面积底色。
- 透明背景：无白底、无投影底板、无边框；边缘 alpha 干净。
- 空状态插画为可选项，本轮暂缓，不占两项名额。

## 4. 小尺寸识别与取舍

识别优先级（从高到低）：顶部翘起发束 → 蓝色眼睛 → 白花＋蓝结＋下垂坠饰的组合 → 趴边双手。

- 48px：以上四项均可读，花可保留五瓣轮廓。
- 32px：保留发束、蓝眼、花与结的整体剪影，坠饰简化为一段下垂蓝线。
- 24px：只保发束、蓝眼与深蓝轮廓色；花与结合并为一个小蓝色点缀，**不强行塞满五瓣与叶片**。细节宁可省略，不可糊成噪点。

## 5. 配色角色映射

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 主背景 | `#F7F4EF` | 页面底 |
| 面板 | `#FFFDF9` | 卡片、输入区 |
| 次底 | `#F0ECE7` | 侧栏、悬停、分隔区块 |
| 主文字 | `#4C4540` | 正文 |
| 次文字 | `#716860` | 由建议值 `#7B726B` 稍加深，适用于三个浅色底上的普通小字 |
| 装饰边框 | `#D8D1C8` | 非关键分隔；不作为输入框/焦点状态唯一标识 |
| 柔粉 | `#DFAEBB` | 仅作底色/点缀 |
| 淡紫 | `#C9BED8` | 仅作底色/点缀 |
| 深玫瑰 | `#96536A` | 链接、焦点、强调按钮；按钮可配白字 |
| 功能边界 | `#8B8177` | 必须独立辨认的控件边界，避免所有分隔线一律加深 |

- 粉、紫适合作底色与角色呼应，**不能默认承载白字**；其上的文字沿用 `#4C4540` 这类深色。
- Codex 已按 WCAG 相对亮度公式核算静态配色，见 [对比度记录](P1-COLOR-CHECK.md)。这些结果只证明不透明纯色组合，不替代 DSH 的最终计算样式、悬停状态和代码高亮检查。

## 6. 首版范围：浅色、字体、布局

- 首版浅色优先，只覆盖上表实际用到的令牌。
- 深色策略确定为释放本插件令牌覆盖，沿用宿主当前深色主题与用户偏好；不强制切回浅色，不创建新深色配色。进入浅色后恢复本插件覆盖，具体事件处理与回退在 P2 测试。
- 保留系统字体与代码字体，不引入字体依赖。
- 保留原有布局、侧栏宽度、控件密度与交互；手绘只出现在角色与必要细节上。
- 不做全屏壁纸、粒子、动画与大面积装饰纹理。

| 侧栏角色 | `assets/characters/sidebar-character.png` | 1254×1254，RGBA PNG | 48–96px 候选；仅在已有区域足够时使用 | 48 / 64 / 96px，待测 | 目标四周 ≥8%，主体当前最小留白 15.63% |

留白以 alpha ≥32/255 的主体包围盒计算；低透明度边缘像素另记，不能把该阈值当成全部背景像素均为零透明度。当前是生成母版候选，不是已压缩的发布资源。

通过条件（每项独立判定）：
- 侧栏角色：48px 以上检查“翘发＋蓝眼＋趴边双手”；若原槽只能容纳 24–32px，改用头像，不扩大侧栏或重做布局。
- 头像：24/32px 下五官不糊成一团；16px 只检查轮廓，不承诺饰件细节可辨。圆形/圆角裁切须在实际容器检查。
- 两者均需在 `#F7F4EF`、`#FFFDF9`、`#F0ECE7` 三种底色上预览，确认无底板或缩放白边；深蓝角色轮廓是必要特征，应保留。
