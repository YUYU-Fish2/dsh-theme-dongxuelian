计算：每个 sRGB 通道归一化后，`c ≤ 0.04045` 时取 `c / 12.92`，否则取 `((c + 0.055) / 1.055)^2.4`；亮度为 `0.2126R + 0.7152G + 0.0722B`；对比度为 `(L亮 + 0.05) / (L暗 + 0.05)`。

这不是整套界面无障碍认证。代码语法色、半透明层、实际令牌覆盖、交互状态、真实窗口与字体渲染仍待 P2–P5 检查；保留原代码字体，不为手绘效果降低正文清晰度。
