# P7 冷白雾蓝与人物背景修订

2026-10-19。用户要求人物背景适量、不能只有图标，并委托检索二创后自行搭配更符合冬雪莲的颜色。此要求修订 P1 的“蓝色不能作为界面主色”“仅小头像”限制；轻量、官方接口、可撤销与阅读优先仍有效。

## 调研与选择

- [アカババァ会员插画作品集](https://www.foriio.com/works/470454)：已在浏览器实际查看银白发、紫色阴影/眼睛、深蓝花饰与蓝蝶、多表情Q版。身份由作者作品标题与频道链接核对。
- [東雪蓮一蓮托生装扮展示](https://www.bilibili.com/opus/958115227033927704)：已实际查看蓝紫帽饰、银白发、深蓝与少量亮粉的插画和同画不同构图。它们是同一组作品，不能充作三位画师的独立样本；展示页未给出完整画师署名，不能编造。
- [眠眠2023生日图](https://home.gamer.com.tw/artwork.php?sn=5761542)：搜索服务读取403，但浏览器最终可访问并实际看过画面。银白长发、蓝黑服饰，与浅粉/浅青/淡紫生日背景形成柔和反差；本主题取其浅底搭深色主体的层次，不照搬生日元素。Twoucan与曲绘页未看像素，不作为已经观察的视觉证据。
- 外部作品只参考颜色、明暗与构图，不下载、复制入包，不把装扮展示当作可免费分发的素材。保留项目原参考里白花、蓝眼、蓝结与晶体饰件的Q版手绘身份，不混用二创的所有服饰设定。

考虑三条路线：冷白雾蓝（采用，适合阅读与现有白发蓝饰）；高饱和蓝紫粉（只借少量淡紫，长时间聊天过强）；大面积深蓝（暂不另造深色方案，保留宿主深色）。

## 色板

底色 #F3F6FC，面板 #FCFDFF，侧栏/悬停 #E8EEF8；主文字 #293750，次文字 #58647C；淡边界 #CED8E8，功能边界 #78879F；强调 #435D9D，hover #354B82，白色按钮文字；用户气泡 #E0E9F8，选中/高亮 #E4E0F2。次文字由初稿#5C6981加深，确保淡紫选中底4.60:1；功能边界由#8392AA加深，侧栏底3.13:1。由 Codex 计算不透明组合对比度，再检查真实窗口。保留代码语法色、字体与错误语义。

## 构图与接入

复用已有两张生成图，不为增加人物量新造角色设定。趴边母版等比导出512px透明WebP，头像192px不变；不裁切/改画。主构图在聊天区右下，侧栏底部为次要呼应；不重复平铺，不添动画或设置页。标题栏重复头像移除，品牌24px头像保留。

通过官方 shell.overlay 列表槽注册独占 id 的 SceneStyle，仅渲染 style 节点，不在高层前景叠图片。CSS 限于官方 data-slot 容器及其直接根节点，通过背景伪元素绘制；不依赖 hash 类名、不直接改DOM/用户设置。使用隔离堆叠与负层级，将图放在正文下；pointer-events:none，不占布局。聊天态降低图的强度，空白态可更清楚；窗口变窄收敛尺寸，侧栏收起隐藏侧栏装饰。最终数值以真实预览调整。

浅色主题、品牌槽、SceneStyle 共用现有事务。深色、停用、owner消失均释放，回浅/owner重声明恢复一份；第二项注册失败逆序回滚主题与品牌。不改变 Host 路由范围。
